# Contributing

Thanks for your interest in improving `Wallettrial_2`.

## How To Contribute

1. Fork the repository
2. Create a feature branch
3. Make focused changes with clear commit messages
4. Test your changes locally
5. Open a pull request with a short explanation of what changed and why

## Contribution Guidelines

- Keep changes small and easy to review
- Preserve the existing console-based workflow unless the pull request clearly proposes a broader refactor
- Prefer readable Java code over clever abstractions
- Update documentation when behavior changes
- Do not commit secrets, personal data, or machine-specific files

## Suggested Areas

- Input validation improvements
- Better error handling
- Test coverage
- Refactoring for maintainability
- Security improvements for credential storage
- UI or usability improvements

## Pull Request Checklist

- The project still builds successfully
- Documentation is updated if needed
- New behavior is explained clearly in the pull request
- No unrelated files are included by accident
